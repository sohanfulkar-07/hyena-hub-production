# The Hyena Hub — Design System Documentation

## Color Palette
- **Obsidian Black**: `#060608` (Primary Page Background)
- **Charcoal Dark**: `#121215` (Panel Surface)
- **Champagne / Golden Gold**: `#D4B44A` / `#F59E0B` (Primary Accent & CTAs)
- **Cyber Indigo**: `#4F46E5` (Secondary Ambient Accent)
- **Soft Lavender**: `#DDD6FE` (Badge Accent)

## Typography
- **Headings**: `Playfair Display` / `Space Grotesk` (Serif & Modern Display)
- **Body & Controls**: `Inter` / `Plus Jakarta Sans` (Sans-serif)
- **Technical & Indicators**: `Monospace` (Uppercase Tracking 0.1em)

## Glassmorphic Tokens
- `backdrop-filter: blur(35px)`
- `border: 1px solid rgba(255, 255, 255, 0.1)`
- `box-shadow: 0 30px 80px rgba(0, 0, 0, 0.85)`
